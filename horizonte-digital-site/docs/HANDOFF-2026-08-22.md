## Arquitetura técnica

- Node.js `>=22.13.0`;
- Next.js 16.2.6;
- React 19.2.6;
- TypeScript;
- Vinext + Vite;
- execução em Cloudflare Workers;
- banco D1 com binding lógico `DB`;
- armazenamento R2 com binding lógico `BUCKET`;
- Drizzle ORM e migrações SQL;
- service workers e manifests separados para Horizonte IA e área da equipe.

Arquivos centrais:

- `app/page.tsx`: página pública, divisões, projetos e planos;
- `app/globals.css`: todo o sistema visual e responsividade;
- `app/layout.tsx`: metadados sociais e layout raiz;
- `app/horizonte-ia/`: página, chat local, PWA e editor;
- `app/equipe/`: login e espaço de trabalho da equipe;
- `app/api/equipe/`: autenticação, tarefas, mensagens, presença, anexos e notificações;
- `lib/team-auth.ts`: participantes, senhas e sessões;
- `lib/team-tasks.ts`: tarefas, mensagens e notificações;
- `lib/team-conversations.ts`: conversa geral;
- `lib/web-push.ts`: notificações push;
- `db/schema.ts`: esquema completo do banco;
- `drizzle/`: histórico de migrações;
- `.openai/hosting.json`: identidade do projeto e bindings lógicos;
- `public/`: imagens, ícones, manifests, service workers e APKs;
- `android-app/`: código usado para gerar o aplicativo Android;
- `tests/rendered-html.test.mjs`: testes do HTML renderizado.

## Como trabalhar localmente

Na pasta do código:

```bash
npm install
npm run dev
npm run build
npm test
npm run lint
```

Somente quando houver mudança deliberada em `db/schema.ts`:

```bash
npm run db:generate
```

Não execute geração de migração por rotina, pois isso pode produzir arquivos desnecessários.
